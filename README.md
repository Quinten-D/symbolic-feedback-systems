# symbolic-feedback-systems
This repository contains code produced for my master's thesis: "Symbolic Feedback Systems for Constrained Perception Problems"

The thesis is available [here](https://kuleuven.limo.libis.be/discovery/fulldisplay?docid=alma9995299315301488&context=L&vid=32KUL_KUL:KULeuven&search_scope=All_Content&tab=all_content_tab&lang=en).

## Abstract
The purely neural approach to computer vision can still fall short for constrained perception problems when input is sufficiently complex. This is the case for perception of images of sudoku games, called the visual sudoku perception problem. The predict then optimize approach to this problem performs notably better, as it uses neural perception and symbolic constraint optimization to return the most probable valid sudoku perception. By reasoning over the sudoku rules this method ensures that its output doesn’t violate any constraints. This thesis proposes an improvement on the predict-then-optimize method which makes full use of the symbolic reasoning capabilities of its constraint solver. Naive neural predictions are used to find the top-k most probable valid sudoku perceptions, from which symbolic feedback is constructed. This feedback identifies all digits for which the symbolic constraint solver is sure about their inferred values and all digits for which the solver is unsure. An additional perception network called the second look network will make new predictions for all unsure digits, possibly informed by the feedback concerning the sure digits. After this, the refined perceptions are used to decide upon a final output of the system. Experimental results show that symbolic feedback is capable at detecting digits with poor predictions through reasoning. Making new, more informed predictions for those digits before reaching a final decision proved beneficial. Overall, symbolic feedback is able to significantly improve perception accuracy with an acceptable increase in inference time.
